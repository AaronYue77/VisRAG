# A/B/C 共用的评测协议

## 数据与边界

- `smoke`：Attention 与 CLIP 两份技术论文，27 页、10 道人工编写并核对证据的题。英文问题用于英文文档检索，另有中文阅读译文。全部属于开发冒烟集；不能用它估计泛化能力。
- `vidoseek`：作者公开标注中确定性选取 100 题，开发集 50 题、最终测试集 50 题。按原始文档分区；同一文档的相近页面不会跨分区。
- 按文档名固定 SHA256 排序交替分 dev/test，然后在各分区按题型抽取：2d_layout 14 题，其余 text/table/chart 各 12 题。采样种子、源数据 revision、文件哈希、具体问题 ID 保存在 `protocol.json` 和仓库 `data/vidoseek-selection.json`。
- 检索语料库为这 100 题涉及的文档，不是完整 ViDoSeek 语料库。数字不能与原论文排行榜直接比较。语料中同时含 dev/test 文档属于检索任务设定；问答模型看不到 gold 标签。
- 当前没有训练集。C 阶段新增训练数据时，需要排除全部 dev/test 文档与重复/近重复内容。仅按问题行随机切分不够。
- 测试集已封存。现在只调开发集；确定 A/B/C 方案后显式 `--final-test` 才运行最终测试。若看过测试答案并据此改方案，应重新划分未使用的测试数据，不能继续称其为未见测试。

## 每道题的 JSONL 字段

| 字段 | 含义 |
|---|---|
| `question_id / question / question_zh` | 稳定问题 ID、实际英文查询、可选中文译文 |
| `reference_answer / answer_aliases / reference_pages` | 参考答案、预先固定的等价写法、1 起始证据页 ID |
| `document_ids / split / question_type / gold_origin` | 文档分组、分区、题型、标签来源 |
| `retrieved_pages` | 每页的 page_id、doc_id、page、rank、score、text_source、pdf_sha256 |
| `answer / raw_output` | 解析答案、模型完整原始输出；非法格式仍保留 |
| `citations / citation_labels / invalid_citations / parse_ok` | 从 P1/P2 映射到实际页面的引用、无效引用、解析状态 |
| `retrieval_seconds / prepare_seconds / generation_seconds` | 检索、输入图片准备、GPU 生成耗时，分别保存 |
| `image_paths / image_sizes / input_tokens / peak_cuda_gib` | 实际输入图片、像素尺寸、token 数、峰值分配显存 |
| `model / model_revision / config_sha256 / source_sha256` | 模型与代码/配置版本 |
| `status / error / issue_id` | 执行状态；遇到异常后关联 TXT 记录 |
| `metrics` | 本题检索、答案匹配和引用页重合指标 |

每个运行目录还有 `config.json`、`provenance.json`、`source_snapshot/`、`summary.json`、`运行报告.md`。模型/数据哈希、依赖版本写入配置；新参数或代码使用新 run-name，避免覆盖旧实验。相同配置可继续未完成题目；已失败的题不会在原运行里悄悄被替换。

## 指标不能混用

- Hit@k：至少一个标注证据页进入 Top-k 的问题比例。
- Recall@k：每题召回的标注证据页数 / 该题全部标注证据页数，再宏平均。多页问题仅命中一页，不等于完整召回。
- MRR@k：Top-k 中首个相关页排名的倒数，未命中为 0，再平均。
- normalized EM / token F1：按固定别名与规范化规则匹配，是诊断指标。长答案的等价改写可能被低估。
- citation_gold_hit：输出引用是否与标注证据页有交集。命中页码不等于引用内容支持答案；需要人工核对。
- json_parse_ok：格式是否有效。答案数字正确但结构非法，与真正完成接口契约是两回事。

当前是离线同题对比实验，不能称为真实线上 A/B 测试。后续比较 A/B/C 时保持题目、语料、VLM、像素与解码参数相同；按文档做成组 bootstrap 估计差值置信区间，防止把同一文档的多题误当作独立样本。100 题也只是小规模诊断集。

错误归因先做检查顺序，不直接当成因果结论：标注页未召回 → 检索候选问题；标注页已召回但答案错 → 阅读/定位/生成候选问题；有效输出却引用错误 → 引用问题。其他页面可能重复包含答案，必须看图片确认。
