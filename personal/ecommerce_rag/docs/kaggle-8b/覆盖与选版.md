# 全库覆盖、20 类照片抽样与 C 阶段选版

| 检查层次 | 实际范围 |
| --- | --- |
| 商品库及全文索引 | 147,702 条、576 类、32 站点 |
| 全库检索评测 | 120 道查询都检索全库，查询是抽样 |
| 固定证据问答 | 210 道，主商品覆盖 35 个类目 |
| 商品照片专项 | 20 类、175 道，按商品形态和视觉难点抽样 |

原 5 类各有 20 道。耳机侧重配件和局部特征，椅子和桌子侧重结构、遮挡与局部，鞋和背包侧重颜色、细节和视角。增补 15 类各 5 道，故意跨越多种形态。饮用杯考透明轮廓和重叠计数，机油、洗涤剂、洗发水和咖啡考包装小字、数值及单位，扳手、灯泡和耳饰考反光或接口，运动球、玩具、母婴用品、文件夹、宠物用品、花盆和乐器配件覆盖场景、纹理、遮挡与细物体。每个新增类目目视检查 8 个家族候选，选 5 张与题意相符的官方商品图。每类 5 道适合发现错例，无法估计该类目总体正确率。

## 120/50 配置已通过切换门槛

新旧适配器使用同一 Qwen3-VL-8B-Instruct、同一 C1 提示、同一图像页、4-bit NF4 与 FP16。120 道训练题使用同一超参训练 1 轮，共 60 次有效更新。训练、开发、原冻结集与新增照片之间没有商品家族或 SKU 交叉。

| 评测 | 旧 60/25 | 新 120/50 |
| --- | ---: | ---: |
| 原冻结问答 | 199/210 | **201/210** |
| 原 5 类照片 | 74/100 | **75/100** |
| 新 15 类照片 | 44/75 | **47/75** |
| 20 类照片合计 | 118/175 | **122/175** |
| 新增开发题 | 17/25 | **18/25** |

原 310 道新增通过 3 道，新增照片新增通过 3 道，两套均无逐题退化。改善包括单位和标点、中文答案词形以及证据不足时的拒答动作格式。玩具和扳手等新增小样本仍有较多严格未通过案例。详细分层与变化见 [主集升级验收](升级验收.txt) 和 [跨类目照片验收](跨类目照片验收.txt)。
