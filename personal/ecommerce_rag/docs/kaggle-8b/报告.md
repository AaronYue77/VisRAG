# Kaggle 8B 训练与 310 题验收

同一 Qwen3-VL-8B-Instruct 官方 Kaggle 快照，4-bit NF4、FP16、Tesla T4。C0 用原提示，C1 加上字段、单位和引用核对，C2 使用相同 C1 提示并重载 QLoRA。训练使用 60 道独立家族问题，1 epoch、30 次更新、212,992 个可训练参数，训练峰值 10.24 GiB。25 道开发题单独报告。

| 严格通过 | C0 | C1 | C2 |
| --- | ---: | ---: | ---: |
| 单字段 | 59/60 | 59/60 | 59/60 |
| 双商品读值 | 45/50 | 45/50 | 48/50 |
| 单位、表格与图表 | 35/40 | 36/40 | 36/40 |
| 引用与证据充分性 | 30/30 | 30/30 | 30/30 |
| 信息缺失与拒答 | 26/30 | 26/30 | 26/30 |
| 问答合计 | **195/210** | **196/210** | **199/210** |
| 椅子照片 | 18/20 | 17/20 | 18/20 |
| 耳机照片 | 14/20 | 14/20 | 14/20 |
| 桌子照片 | 14/20 | 14/20 | 14/20 |
| 鞋照片 | 9/20 | 10/20 | 13/20 |
| 背包照片 | 15/20 | 15/20 | 15/20 |
| 照片合计 | **70/100** | **70/100** | **74/100** |

C0→C1 的正式问答有 2 道改善和 1 道退化，照片各有 1 道。C1→C2 的正式问答改善 3 道，照片改善 4 道，这两组均无严格口径下的退化。双商品的改善主要来自按要求输出商品编号，原输出已读对数值。照片的部分改善来自按预设答案使用中文词形。LoRA 的严格通过率小幅上升，独立照片读值能力仍需用更多样的图片验证。

三组在 30 道缺失问答里均正确拒答 26 道，对 180 道可回答问答均无误拒答。完整 [分层及配对计数](合并验收.txt)、[统计 JSON](metrics.json)、[逐题变化](paired-changes.json)、[训练记录](训练记录.txt) 可直接查阅。

问答用 ABO 来源值派生资料卡，含 5 道派生条形图。图片包含五类官方商品照片和多角度补测，其中 1 张对官方原图模拟轻度失焦，保留原图和变换参数。两次实验的原冻结题和新增题分别运行，同一适配器以 SHA256 核对后重载。A/B 的全量检索另外用 120 道品牌或型号查询评估，BM25、Dense、RRF 的准确商品 Hit@5 分别为 114/120、58/120、94/120。候选池以来源标签判断，12 个歧义逐条复核。

数据与证据源为 Amazon Berkeley Objects，源许可和署名随本地复现包保存。完整逐题 JSONL、冻结 PDF、原图、模型配置和适配器在本地实验归档。私有 Kaggle Notebook 的使用需要对应访问权限。
